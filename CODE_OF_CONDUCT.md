# Code of conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) as its code of conduct. It applies in the repository (issues, pull requests, discussions, reviews) and wherever someone represents the project.

In short: be respectful and constructive, assume good faith, criticise ideas and code rather than people, and accept that maintainers may edit, hide or remove contributions that break these rules.

## Reporting

Report conduct problems to the maintainer, [@munendra07-tech](https://github.com/munendra07-tech). For a private channel, open an issue titled "Conduct: private contact requested" with no details in it; the maintainer will reply with a way to talk privately and will not discuss the report in public. Reports are handled confidentially, following the Covenant's enforcement guidelines (correction, warning, temporary ban, permanent ban).

Security vulnerabilities are not conduct reports: see [SECURITY.md](SECURITY.md).
